# CODVEDA Level 1 - Task 3: Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on analyzing datasets to identify trends, relationships, and patterns using statistical and visualization techniques.

## Objectives
- Compute summary statistics
- Visualize distributions and relationships
- Identify correlations between features
- Generate insights from the dataset

## Technologies Used
- Python
- pandas
- matplotlib
- seaborn

## Visualizations Performed
- Histograms
- Scatter plots
- Box plots
- Correlation heatmaps

## Project Outcome
Generated meaningful insights and visual interpretations from the dataset for better decision-making.
